---

## Descripción

Este proyecto consiste en el análisis organizacional y el diseño de un sistema interno para la gestión de clientes, proyectos e incidencias de una empresa de desarrollo de software. La solución propuesta busca centralizar la información, mejorar los procesos internos y facilitar la toma de decisiones.

---

## Funcionalidades Principales

- Gestión de clientes.
- Gestión de proyectos.
- Gestión de incidencias.
- Seguimiento de actividades.
- Generación de reportes e indicadores.
